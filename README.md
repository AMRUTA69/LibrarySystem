# Library Management System (Java)

A console-based Library Management System built in Java. It allows users to add books, register members, issue/return books, and persist data to text files.

## ✨ Features

- ✅ Add new books (ID, Title, Author)
- ✅ Register new members (ID, Name)
- ✅ Issue books (with exception handling if already issued)
- ✅ Return books (with exception handling if not issued)
- ✅ File Persistence (saves and loads books/members from `books.txt` and `members.txt`)
- ✅ Simple text-based menu for user interaction

## 🛠️ Technologies Used

- **Language:** Java (JDK 21)
- **Data Structure:** `ArrayList`
- **File Handling:** `BufferedReader`, `BufferedWriter`
